## Key decisions
- Chose vertical slicing over horizontal layers:
  - Chain 1: UI primitives → navigation → Sidebar → AppShell/TopHeader → app layout.
  - Parallel: Login + Landing pages.
  - Parallel: Dashboard + Simulator + 4 placeholder pages.
  - Chain 2: path cleanup → test updates → final verification.
- Added `href` prop to `Button` primitive so it can render `next/link` directly, avoiding invalid `<a><button>` nesting and the complexity of `asChild`.
- TopHeader hidden on mobile (`hidden lg:flex`) to avoid double headers with MobileHeader.
- Preserved all existing state machines and simulator logic; only visual styling changes.
- Use `docs/superpowers/archive/` (git-ignored) to keep old full implementations available as working-tree reference without tracking them in git.
